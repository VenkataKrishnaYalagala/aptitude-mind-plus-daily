# Security policy

This project includes publishing automation for public social media accounts.

Avoid publishing Meta access tokens, account IDs not intended for public use, private student information or other secrets to GitHub. Report a security concern privately through GitHub's **Report a vulnerability** feature, if enabled, or contact the repository owner privately to establish a secure channel.

If a credential is exposed, revoke and rotate it promptly; removing it in a new commit does not remove it from prior Git history. All changes to permission scopes, live-posting gates and publishing endpoints require owner review. Do not include live access tokens in test logs.
